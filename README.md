# ทายแข้งไทยลีก

เกมทายนักเตะไทยลีก 1 ฤดูกาล 2026/27 แบบ Who Are Ya? เล่นได้ไม่จำกัด ทายได้ 8 ครั้งต่อรอบ คำใบ้ 5 ช่อง: สโมสร ภาค ตำแหน่ง สัญชาติ เบอร์เสื้อ

- พิมพ์ชื่อนักเตะได้ทั้งภาษาไทยและอังกฤษ
- เว็บไฟล์เดียว `index.html` ไม่ต้อง build บน Vercel ตั้ง Framework Preset เป็น **Other**
- รายชื่อนักเตะ 461 คนจากหน้าทีมใน Wikipedia (ราวมกราคม–สิงหาคม 2026) อาจยังไม่ครบการซื้อขายช่วงซัมเมอร์
- เกมโดยแฟนบอล ไม่เกี่ยวข้องกับไทยลีกหรือสโมสรใด
